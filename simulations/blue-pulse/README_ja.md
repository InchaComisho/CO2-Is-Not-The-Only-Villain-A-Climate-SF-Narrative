# Blue Pulseの概念的な展開シミュレーション

[English Version](README.md)

> **重要な免責事項**
>
> これは、架空のBlue Pulseプロジェクトのための、簡略化した教育用の簡易モデルです。
> 現実の気候予測ではなく、工学的な検証ではなく、政策の提言ではありません。
> すべての出力は、述べた仮定のもとでの、例示的なシナリオの推計です。

## 目的

このシミュレーション・モジュールは、架空のBlue Pulseプロジェクトが、単一の試験ユニットから
100,000ユニット以上までの異なる展開規模で、どう拡大しうるかを推計します。

次の複合的な効果をモデル化します。

- **OBS**（海洋呼吸システム）— 下からの深層海洋の曝気
- **UMC**（超音波ミスト冷却）— 上からの気化による表層の冷却

スケーリングは非線形です。被覆は指数的に飽和する一方で、介入リスクは大規模で便益よりも速く増えます。

| ファイル | 説明 |

## クイックスタート

```bash
cd simulations/blue-pulse
python blue_pulse_simulation.py
```

異なるパラメータのバリエーションで実行するには：

```bash
python blue_pulse_simulation.py --variant low
python blue_pulse_simulation.py --variant high
```

## シナリオ

| ユニット数 | 規模 |
|---|---|
| 1 | 単一の概念実証ユニット |
| 100 | 小規模な現地アレイ |
| 1,000 | 沿岸の実験的な回廊 |
| 10,000 | 大規模な湧昇域への展開 |
| 50,000 | 海盆規模の実験的インフラ |
| 100,000 | 非常に大規模な展開（飽和の領域） |

## モデルの主な挙動

- **被覆**は、`1 - exp(-total_area / target_area)`として飽和する
- **リスク**は、`effective_coverage ** 1.35`に、霧、ガバナンス、循環の不確実性の要素を加えて増える
- **便益**は、非現実的な出力を防ぐために、モデルが定める最大値で頭打ちになる
- 大規模では、リスク指標が生態系回復指標よりも速く増える

## 注意事項

- これらの出力を、現実の海洋学のデータと比較してはいけません。
- このモデルは、現実の海洋循環、現実の気象のフィードバック、現実の炭素循環のトン数、
  現実の生態学的な力学をシミュレートしません。
- OBSとUMCは、現実世界では、運用規模で実証されていません。
