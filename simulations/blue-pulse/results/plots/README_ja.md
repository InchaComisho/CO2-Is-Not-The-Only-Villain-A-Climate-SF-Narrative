# Blue Pulseシミュレーションのプロット

[English Version](README.md)

> **重要：**これらのプロットは、簡略化した教育用の簡易モデルの出力です。
> 現実の気候予測ではありません。架空のBlue Pulseプロジェクトのための、
> 例示的なシナリオの比較です。

## 生成されるプロット

| ファイル | 説明 |
|---|---|
| `unit_count_vs_regional_sst_reduction.png` | ユニット数に対する、地域のSST低下の例示的な推計 |
| `unit_count_vs_heatwave_day_reduction.png` | ユニット数に対する、海洋熱波の日数の削減の例示的な推計 |
| `unit_count_vs_ecosystem_recovery_index.png` | ユニット数に対する、生態系回復の代理指標 |
| `unit_count_vs_risk_index.png` | 生態系回復指標と介入リスク指標 |

## 注記

- スケーリングは非線形です。飽和の式`1 - exp(-area / target_area)`が用いられています。
- ユニット数が多いと、リスクは便益よりも速く増えます。
- すべての軸の値は、例示的な推計であり、現実の測定ではありません。
