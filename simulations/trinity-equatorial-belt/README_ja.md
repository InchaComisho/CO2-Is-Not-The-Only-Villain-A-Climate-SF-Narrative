# 三位一体の赤道帯の概念シミュレーション

[English Version](README.md)

> **重要な免責事項**
>
> これは、架空の三位一体モデルのための、簡略化した教育用の簡易モデルです。
> 現実の気候予測ではなく、工学的な検証ではなく、政策の提言ではありません。
> すべての出力は、例示的なシナリオの推計です。

## 目的

このモジュールは、架空の三位一体モデルが、簡略化した赤道帯に展開されたとき、
どう拡大しうるかを推計します。次を組み合わせます。

- **OBS** -- 海洋呼吸システム／深層海洋の曝気（下から）
- **UMC** -- 海と陸の上での超音波ミスト冷却（上から）
- **土壌再生** -- 陸上の炭素吸収源の回復

Blue Pulseのみのモデルとは異なり、このシミュレーションは、海洋の熱、陸の熱ストレス、
土壌の炭素吸収源、保水に、同時に対処します。

## 展開シナリオ

| ユニット数 | 規模 |
|---|---|
| 1 | 単一の概念実証ユニット |
| 100 | ごく小規模なパイロット |
| 1,000 | 小規模な地域試験 |
| 10,000 | 地域的な展開 |
| 50,000 | 大規模な展開 |
| 100,000 | 海盆規模のインフラ |
| 250,000 | 大陸規模（ストレステスト） |
| 500,000 | 極端なシナリオ（簡易モデルの限界） |

## モデルの主な挙動

- 被覆は、`1 - exp(-effective_area / target_area)`として飽和する
- 海と陸は、異なる対象面積で、別々にモデル化される
- 三位一体の相乗係数が、複合的な効果を増幅する（1.10倍）
- 大規模では、リスクが便益よりも速く増える
- ガバナンスのリスクは、最大のシナリオ（500,000ユニット）に対して正規化される

## 格子に関する注記

赤道帯の格子は、簡略化した簡易マスク（5度のセル、緯度-15から15）です。
陸地は、おおよその長方形の範囲です。現実の地理モデルではありません。
