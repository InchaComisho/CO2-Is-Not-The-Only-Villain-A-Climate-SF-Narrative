# 三位一体モデル

[English Version](trinity-model.md)

## 短い定義

三位一体モデルは、第11話の中心的な気づきです。地球温暖化は、どれか一つの対策では対処できません。地球の冷却能力と炭素固定の循環が回復するには、三つの層が一緒に動かなければなりません。

三つの層は次のとおりです。

1. **深層海洋の曝気** — 海洋循環を再始動させ、海洋の炭素吸収能力を回復させる
2. **ミスト冷却** — 気化冷却によって、地表での過剰な熱の流入を減らす
3. **土壌再生** — 腐葉土、微生物、生物的な土壌の活動を通じて、陸上の炭素吸収源を回復させる

## 物語における役割

三位一体モデルは、第11話における概念上の突破口です。海洋の熱、OBS、UMC、Blue Pulse、ガバナンスをめぐる苦闘という、九つのエピソードにわたる断片の蓄積の後、主人公はようやく全体像を見ます。

> 「排出削減は蛇口を絞る。でも、循環システムそのものも修理しなければならない。」

排出削減だけでは、すでに海洋にある熱は取り除けません。OBSとUMCだけでは、炭素吸収源は回復しません。土壌再生だけでは、海洋は冷えません。三つの層が揃って初めて、温暖化が乱したものを回復する方向へ動けます。

第12話では、三位一体モデルを、スーパーエルニーニョの複合リスクの地図を読み解くレンズとして適用します。

## 概念的な意味

Master / InchaComishoのフレームワークの中で、三位一体モデルは、単一原因の思考から、システム思考への転換を表します。

- CO₂の削減 ＝ 蛇口を絞ること（必要だが、十分ではない）
- 海洋の曝気 ＝ 循環ポンプを再始動すること
- ミスト冷却 ＝ 地表での熱の流入を減らすこと
- 土壌再生 ＝ 損なわれた炭素貯蔵システムを修復すること

このモデルは、どれか一つのアプローチを選ぶものでは、明確にありません。気候の回復を、本質的に多層的なものとして位置づけ、三本の柱が互いを強め合います。

- 地表が冷えると、海洋の曝気がより効果的になる
- 回復した海洋循環は、プランクトンと海洋の炭素吸収を支える
- 回復した土壌は、水分を保ち、地表の熱を減らし、炭素を隔離する
- 三つが揃うと、極端な現象を駆動する熱ストレスが減る

## 類似する、あるいは隣接する現実世界の考え方

類似する、あるいは隣接する考え方には、次のものがあります。

- 統合的な気候適応のフレームワーク

- 炭素循環の回復
- 気候緩和への生態系ベースのアプローチ
- 複数の部門にわたる気候政策の調整

これらは、三位一体モデルと同一ではありません。三位一体モデルは、この物語の中での、特定の概念的な統合です。隣接する現実世界の考え方は、重なる領域を探りますが、ここで述べる統合的で循環に焦点を当てたフレームワークではなく、個々の構成要素に対処することが多いです。
