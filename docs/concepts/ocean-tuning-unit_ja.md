# 海洋調律ユニット

[English Version](ocean-tuning-unit.md)

## 短い定義

海洋調律ユニット（Ocean Tuning Unit）、略してOTUは、海洋側の気候介入に結びつく、より技術的なインフラの概念です。物語の概念的フレームワークでは、OTUは、OBSとUMCの展開を支える、モニタリング、測定、制御、順応的管理の層を指します。ハードウェアだけでなく、知能とフィードバックのインフラです。

## 物語における役割

OTUは、Blue Pulseの技術的な背骨として登場します。単一のエピソードの中心的な登場人物ではありませんが、第8〜10話でなされる決定の背後にある、暗黙のインフラです。介入が機能しているかを知ること、続けるか止めるか、チリのような新しい場所に拡大する方法には、OTUが表すようなフィードバックと制御が必要です。

## 概念的な意味

Master / InchaComishoのフレームワークの中で、OTUは次を表します。

- **モニタリング** — 海洋の温度、循環、化学、生物学的な指標の、継続的な測定
- **調律** — リアルタイムのフィードバックに基づく、OBSとUMCの強度、場所、タイミングの調整
- **インフラ** — 介入の機器と測定システムの両方を収める、物理的な展開ユニット
- **ガバナンスとのインターフェース** — OTUから流れるデータが、第8話と第10話で描かれる人間の意思決定のプロセスに情報を提供する

この概念は、海洋への介入の主要な課題の一つに対処します。それが機能しているかを、どうやって知るのか？海洋は、ゆっくりした曖昧なフィードバックしか返しません。OTUは、そのフィードバックを読み取れて、行動に移せるものにしようとする試みです。

類似する、あるいは隣接する考え方には、次のものがあります。

- 海洋観測システム（例：Argoフロートのネットワーク）
- 海洋のモニタリング・インフラ
- 順応的な海洋管理
- 海洋への介入のためのリアルタイムのフィードバックシステム

これらは、OTUの概念と同一ではありません。現実世界の海洋観測システムは確立された科学ですが、ここで述べるOTUは、現在の運用の実務を超える、制御と介入の層を加えます。
