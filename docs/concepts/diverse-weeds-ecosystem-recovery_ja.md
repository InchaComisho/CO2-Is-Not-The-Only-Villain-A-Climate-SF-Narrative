# 多様な雑草による生態系の回復

[English Version](diverse-weeds-ecosystem-recovery.md)

## 短い定義

多様な雑草による生態系の回復とは、一般に「雑草」として片づけられがちな、多様で自生する植物の成長が、初期段階の生態系の回復で決定的な役割を果たす、という考えです。このフレームワークでは、多様な雑草は栽培の敵ではなく、裸地や劣化した土壌の最初の癒し手です。

## 物語における役割

この概念は、第11話で、三位一体モデルの議論の一部として登場します。主人公が、土壌再生は実際にはどう始まるのかと尋ねたとき、答えは、まず雑草を生やすこと、です。多様な雑草は、裸の土壌を覆い、乾燥と浸食を防ぎ、枯れるときに有機物を加え、昆虫その他の生物を引き寄せ、微生物を支え、より複雑な植物群集が発達できる条件をつくります。

## 概念的な意味

Master / InchaComishoのフレームワークの中で、多様な雑草は、自然補完の地表レベルでの表現として位置づけられます。単一種による回復を押しつけるのではなく、生態学的な多様性が、回復の初期段階を導くようにすることです。

フレームワークは、段階的なプロセスを述べます。

1. 裸地あるいは劣化した土壌を、多様な雑草の被覆が発達するよう、放置する、または助ける
2. 雑草が枯れて分解し、土壌に有機物を加える
3. 土壌の水分と微生物の活動が改善する
4. より複雑な植物群集が定着できる
5. 時間とともに、低木、そして樹木が可能になる

これは、単純な回復戦略としての「植樹」と対比されます。生物的な基盤を回復させずに、死んだ土壌に木を植えても、失敗することが多いのです。雑草が先です。

## 注意事項

- この概念は、侵略的な種を野放しに広げさせることを意味しません。地域の生態学的な管理、在来種の優先、侵略的な種のモニタリングは、依然として重要です。
- ここで述べる多様な雑草による生態系の回復は、概念的なフレームワークであり、特定の回復のプロトコルではありません。
- 現実世界の生態系の回復には、場所ごとの評価、モニタリング、順応的管理が必要です。
