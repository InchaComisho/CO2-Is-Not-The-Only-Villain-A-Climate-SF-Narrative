# 土壌再生／腐葉土／微生物

[English Version](soil-regeneration-leaf-mold-microorganisms.md)

## 短い定義

この物語における土壌再生とは、有機物の蓄積、腐葉土の形成、微生物の活動、菌類のネットワーク、土壌の生物的なプロセスを通じて、土壌の生きた質を回復させることを意味します。健全な土壌は、単なる生育の基盤ではなく、炭素吸収源、水の貯蔵庫、そしてそれ自体が生きた循環システムとして示されます。

## 物語における役割

土壌は、第1〜2話で、炭素固定システムの議論の一部として登場します。微生物、森林、土壌が、文明が損なってきた炭素吸収システムとして、プランクトンと並べて挙げられます。第11話では、土壌再生が三位一体モデルの第三の柱として名づけられます。陸上の炭素吸収源を回復させなければ、海洋側と大気側の介入は不完全なままです。

## 概念的な意味

Master / InchaComishoのフレームワークの中で、土壌再生とは、次を意味します。

- **腐葉土** — 生きた土壌の基盤をなす、分解した有機物。化学肥料では置き換えられない、ゆっくりした生物的なプロセス
- **微生物** — 有機物を分解し、窒素を固定し、根系を支え、すべての陸上生態系の目に見えない基盤をなす、細菌、菌類、その他の土壌生物
- **菌類のネットワーク** — 栄養と水を分け合う、植物間の地下のつながり
- **腐植の形成** — 土壌における、安定した有機炭素の長期的な蓄積
- **土壌の生物活動** — これらすべてのプロセスの総体。土壌を、不活性な基質ではなく、生きたシステムにする

物語の重要な主張は、現代の農業、森林破壊、土地利用がこれらのプロセスを乱し、土壌が炭素、水、生命を保持する能力を低下させ、温暖化と生態系の崩壊の両方を加速させている、というものです。

## 類似する、あるいは隣接する現実世界の考え方

類似する、あるいは隣接する考え方には、次のものがあります。

- 再生型農業
- 堆肥化と有機物の管理
- 土壌炭素の隔離に関する研究
- 腐植の形成と回復
- 微生物生態学と土壌の健全性の科学
- 生物的な土壌改良による生態系の回復

これらは、この物語の概念と同一ではありません。現実世界の土壌炭素の科学は、理解と応用のさまざまな規模で、このフレームワークの一部に取り組んでいます。物語は、それらを、土壌の中の生物的な循環の回復への、一つの重点にまとめています。

## 注意事項

- ここで述べる土壌再生は、概念的なフレームワークであり、特定の農業実践の手引きではありません。
- 物語は、腐葉土と微生物だけで地球温暖化を逆転できるとは主張しません。
- 土壌炭素と大気中のCO₂との関係には、複雑な時間スケール、土地利用の歴史、生態学的な力学が関わり、物語は物語上の目的のためにこれを単純化しています。
