# 炭素固定の循環

[English Version](carbon-fixation-cycle.md)

## 短い定義

この物語における炭素固定の循環とは、炭素を吸収し、貯蔵し、循環させ、安定させる、生きたシステムの総体を意味します。次のものを含みます。

- 海洋の植物プランクトン
- 森林
- 土壌微生物
- 腐葉土と腐植
- 湿地
- 草原
- 海洋と陸上の食物網

第1〜2話の中心的な主張は、人類の文明が、CO₂の排出にほぼ全面的に焦点を当てる一方で、これらの固定システムが弱まるのを許してきたということです。吸収され貯蔵される量が減っているため、同じ量のCO₂でも、より危険になっています。

## 物語における役割

炭素固定の循環は、物語の基礎となる洞察です。第1話は、AIの浴槽のたとえを通じて、この概念を導入します。

> 「CO₂は、浴槽に流れ込む水のようなものだ。海洋、森林、土壌、微生物、プランクトンは、排水と貯蔵のシステムの一部だ。排水口が同時に詰まってしまえば、水位ははるかに速く上がる。」

第2話は、炭素固定システムが実際には何であるかを解き明かします。第12話までに、最終的な統合は、炭素固定の循環を、地球直接冷却が排出削減以上のものを必要とする究極の理由として位置づけます。

## 概念的な意味

Master / InchaComishoのフレームワークの中で、炭素固定の循環は、地球の気候の安定を支える、生物的なインフラを表します。土壌の劣化、森林の喪失、海洋の成層化、プランクトンの減少、微生物の崩壊を通じてそれが弱まると、惑星は緩衝能力を失います。

物語は、次を区別します。
- **炭素固定** — 大気あるいは海洋から、CO₂を能動的に吸収すること
- **炭素貯蔵** — 炭素を、安定した形（腐植、木材、貝殻、堆積物）で保持すること
- **炭素循環** — 生命を支え、バランスを保つ形で、生態系を通じて炭素を動かすこと

循環が健全であるためには、この三つのすべてが機能しなければなりません。
