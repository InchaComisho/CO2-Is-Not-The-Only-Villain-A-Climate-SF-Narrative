# Blue Pulseシミュレーションモデル

[English Version](blue-pulse-simulation-model.md)

> **重要：**このシミュレーションモデルは、架空のBlue Pulseプロジェクトのための、
> 簡略化した教育用の簡易モデルです。現実の気候予測でも、工学的な検証でも、
> 政策の提言でもありません。すべての出力は、述べた仮定のもとでの、例示的な
> シナリオの推計です。

## 目的

Blue Pulseシミュレーションモデルは、架空のBlue Pulseプロジェクトが、展開の規模に応じてどう拡大しうるかを探るための、
簡略化した概念的なシナリオのフレームワークを提供します。

物語と教育を目的として設計されています。海洋側の気候介入が、単に強めていけるスイッチではなく、
非線形なスケーリング、飽和効果、規模とともに増すリスクを持つシステムであることを、
読者が理解する助けとなるためです。

シミュレーションは、[`simulations/blue-pulse/`](../../simulations/blue-pulse/)にあります。

## 何をシミュレートするか

このモデルは、次の複合的な効果を推計します。

### OBS — 海洋呼吸システム（下から）

- ナノバブルの柱による、深層海洋の曝気
- 人工湧昇の補助
- 鉛直混合と栄養塩輸送の支援
- 海洋の炭素吸収源の回復（代理指標のみ）

### UMC — 超音波ミスト冷却（上から）

- 海面での気化冷却
- 日中のピーク時の熱の流入の削減
- 影響を受ける領域の上の「薄い傘」の効果

### Blue Pulseの複合効果

OBSとUMCが一緒に働くとき、相乗効果の係数が適用されます。下からの混合が成層化を減らし、
上からの冷却が混合層の再加熱を遅らせます。
ただし、スケーリングは線形ではありません。モデルは、指数的な飽和の式を用います。

```
effective_coverage = 1 - exp(-total_effective_area / target_region_area)
```

ユニット数が少ないとき、被覆はごくわずかです。ユニット数が非常に多いときは、
限界的な被覆の増加が減る一方で、リスクは増え続けます。

## シミュレートしないこと

このモデルは、次を明示的にシミュレートしません。

- 現実の海洋循環の力学や熱塩循環のフィードバック
- 現実の気象システムのフィードバック（嵐の経路、モンスーンのパターンなど）
- 現実の炭素循環のトン数（炭素吸収は代理指標のみ）
- 海洋食物網の現実の生態学的な応答
- 規模での、現実のコスト、エネルギー、インフラの要件
- 現実のガバナンスと規制のプロセス
- 大規模での、現実の生態系への副作用
- 現実の市民や地域社会の反応

## 展開規模のシナリオ

| ユニット数 | 規模のラベル | 概念的な文脈 |
|---|---|---|
| 1 | 単一の試験ユニット | 概念実証。局所的な観察のみ |
| 100 | 小規模な現地アレイ | 慎重なモニタリングのもとで、検出可能な局所的効果 |
| 1,000 | 沿岸の実験的な回廊 | モデルの中で、地域的な効果が現れ始める |
| 10,000 | 大規模な湧昇域への展開 | 楽観的な仮定のもとで、意味のある地域的な改善 |
| 50,000 | 海盆規模の実験的インフラ | 強い信号。リスク指標が急速に増加 |
| 100,000+ | 非常に大規模な展開 | 飽和の領域。リスクが支配的になる |

## モデルの出力

各シナリオについて、モデルは次を計算します。

| 出力 | 説明 |
|---|---|
| `effective_coverage_percent` | 影響を受ける対象領域の割合（%） |
| `local_combined_sst_reduction_c` | 局所的なSSTのピーク低下の推計（°C） |
| `regional_mean_sst_reduction_c` | 地域平均のSST低下の推計（°C） |
| `marine_heatwave_days_reduced_percent` | 熱波の日数の推計削減率（%） |
| `phytoplankton_proxy_increase_percent` | プランクトンの回復の代理指標（%） |
| `carbon_uptake_proxy_increase_percent` | 炭素吸収の代理指標（%、実際のトン数ではない） |
| `ecosystem_recovery_index_0_100` | 重み付き複合指標（0〜100） |
| `intervention_risk_index_0_100` | 複合リスク指標（0〜100） |
| `confidence_level` | 物語上の信頼度のラベル |
| `interpretation` | 平易な言葉によるシナリオの解釈 |

## モデルの主な挙動

**飽和：**被覆は最初は急速に増え、利用可能な対象領域が飽和するにつれて小さくなります。
つまり、被覆が高いときにユニットを追加しても、ユニットあたりの追加の利益は小さくなります。

**リスクの増加：**リスクは`effective_coverage ** 1.35`で増え、被覆そのものよりも速く増加します。
大規模では、リスク指標が生態系回復指標を追い越します。これは、「多ければ多いほど良いとは
限らない」ことを示すための、意図的なモデルの特徴です。

**上限：**すべての出力指標は、非現実的な暴走する出力を防ぐために、モデルが定める最大値で
頭打ちにされます。これらの上限は、パラメータファイルで設定できます。

## 大規模な結果の解釈

展開が50,000台から100,000台以上へ拡大するにつれて、モデルは次を示します。

- SSTの低下の限界的な増加が小さくなる（飽和）
- 生態学的な攪乱のリスクが増える
- UMCによる霧と沿岸の視程のリスクが増える
- ガバナンスと市民の信頼のリスクが、便益よりも速く増える
- 大規模な湧昇による、循環の不確実性のリスクが増える

これは、第8〜10話における物語の中心的な懸念を反映しています。介入の倫理とリスクは、
技術が何をしうるかという技術的な問いから切り離せません。

## 設定

すべてのモデルのパラメータは、次で設定できます。

[`simulations/blue-pulse/config/default_parameters.yml`](../../simulations/blue-pulse/config/default_parameters.yml)

三つのパラメータのバリエーションが利用できます。

- `low` — 悲観的な仮定（効果が小さく、相乗効果が低い）
- `default` — 基準となる仮定
- `high` — 楽観的な仮定（効果が大きく、相乗効果が高い）

## シミュレーションの実行

```bash
cd simulations/blue-pulse
python blue_pulse_simulation.py
python blue_pulse_simulation.py --variant low
python blue_pulse_simulation.py --variant high
```

## 注意事項

- 結果は概念的なものであり、現実の海洋学のデータと比較してはいけません。
- このモデルは物語のための道具であり、工学設計の道具ではありません。
- OBSとUMCは、現実世界では、運用規模で実証されていません。
- リスク指標は、現実のガバナンスのしきい値や安全基準には対応しません。
- 炭素吸収の代理指標は、炭素会計やオフセットの主張には使えません。
