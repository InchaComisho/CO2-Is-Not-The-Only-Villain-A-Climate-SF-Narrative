# 地球直接冷却

[English Version](direct-planetary-cooling.md)

## 短い定義

地球直接冷却は、物語における包括的な概念フレームワークです。地球が本来持つ自然の冷却能力と炭素固定の循環を回復させることを指します。惑星を機械のように制御するのではなく、かつて熱と炭素を管理していた、損なわれたシステムが再び機能するよう助けることです。

## 物語における役割

地球直接冷却は、物語のすべての介入を統一するフレームワークです。最初のエピソードから、AIのキャラクターは、炭素固定のシステム、海洋の熱、土壌の劣化を指摘することで、主人公の「CO₂だけ」という枠組みに異議を唱えます。第11話までに、主人公は三位一体モデルに到達します。地球直接冷却には、同時に働く三つの層が必要だという気づきです。第12話は、このフレームワークの最終的なストレステストとして、スーパーエルニーニョの地図に戻ります。

## 概念的な意味

Master / InchaComishoのフレームワークの中で、地球直接冷却とは、次を意味します。

- **深層海洋の曝気／海洋循環の再始動** — 海洋が呼吸し、鉛直循環を再開できるよう助ける
- **ミスト冷却／気化冷却** — 地表での過剰な熱の流入を減らす
- **土壌再生／腐葉土／微生物** — 生物の活動を通じて、陸上の炭素吸収源を回復させる
- **生態系の再生** — 炭素を吸収し、貯蔵し、安定させる、生きたシステムを回復させる
- **生きた循環システムの回復** — 惑星を機械ではなく、生きたシステムとして扱う

この概念は、気候を支配するジオエンジニアリングについてのものでは、明確にありません。介入を、すでに存在しているが弱まったシステムへの支援として位置づけます。
