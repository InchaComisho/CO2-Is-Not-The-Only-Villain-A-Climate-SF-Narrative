# 深層海洋の曝気

[English Version](deep-ocean-aeration.md)

## 短い定義

深層海洋の曝気は、物語におけるOBSの背後にある、より広い概念的なプロセスです。空気、微細な泡、あるいはナノバブルを、より深い水の層に送り込み、次を助けることを意味します。

- 鉛直方向の動きと混合
- より深い層の酸素化
- 深層から表層への栄養塩の輸送
- 温暖化で弱まった循環パターンの回復

## 概念的な意味

Master / InchaComishoのフレームワークの中で、深層海洋の曝気は、温暖化で弱まった、海洋自身の自然な鉛直循環 — 熱塩循環、湧昇、混合 — を助けるものとして位置づけられます。

この概念は、人工的な循環を強制することではなく、混ざり、呼吸し、栄養塩を循環させるという、海洋が本来持つ傾向を支えることについてのものです。

物語における主な期待される効果：
- 成層化して枯渇した表層での、プランクトンの生産性の再生
- 海洋の炭素吸収能力の回復
- より冷たい深層水の循環による、表層の冷却
- 海洋の食物網の回復の支援

- 物理海洋学における人工湧昇の研究

これらは、この物語で使われる概念と同一ではありません。これらの分野の現実世界の研究は、さまざまな規模と発展段階で、問題の一部を探っています。物語は、これらが実証済みでスケール可能な解決策だとは主張しません。
